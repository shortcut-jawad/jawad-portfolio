## Stack

Plain HTML, CSS and JavaScript, with no build step, deployed on Vercel.

- Type: Space Grotesk, Inter, JetBrains Mono (Google Fonts)
- Palette: ink `#0B0B0C`, bone `#F4F1EA`, lime `#C6FF3D`, orange `#FF5A1F`
- Scroll reveals and count-ups use `IntersectionObserver` and respect `prefers-reduced-motion`

## Run locally

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173.
