A modern, high-performance, dark-themed personal portfolio website built with vanilla HTML, CSS3 (Custom Design System with Glassmorphism & High-Contrast Colors), and JavaScript (ES6+). Built to showcase verified projects, teaching assistant experience, technical skills, and research work.

---

## 🌟 Features

- **High-Contrast Dark Theme**: Custom obsidian slate palette with electric sky-blue (`#38bdf8`) and purple (`#c084fc`) accents, compliant with WCAG AAA typography contrast standards.
- **Interactive Canvas Physics**: Custom HTML5 canvas particle system with dynamic node-connection physics and cursor radial illumination.
- **Responsive Glassmorphism Navigation**: Adaptive navbar with active section scroll-spy, smooth scrolling, and mobile overlay menu.
- **Categorized Skills Matrix**: Interactive tabbed navigation showcasing technical skills across Languages, Frontend, Backend & Databases, DevOps & Cloud, and Software Engineering Concepts.
- **Verified Project Showcase**: Highlights major full-stack and machine learning applications with direct links to live demos, GitHub repositories, research reports, and publication articles.
- **Academic Leadership & TAships**: Timeline detailing 4 semesters of Teaching Assistantships at LUMS (Calculus I, Linear Algebra, Probability).
- **Direct Resume Access**: Downloadable CV integration linking directly to verified credentials.

## 💻 Local Development Setup

To run this portfolio locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shortcut-jawad/jawad-portfolio.git
   cd jawad-portfolio
   ```

2. **Serve the website locally**:
   You can serve `index.html` using any local server (e.g. Python, Live Server, VS Code extension):
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   ```
   Open `http://localhost:8000` in your web browser.
